# Asistente de Conocimiento IA · UX & Interacción

Maqueta navegable y flujo de interacción para un asistente inteligente, diseñada bajo los principios de Experiencia de Usuario (UX) para IA (manejo de estados, transparencia, fuentes trazables tipo RAG y control humano).

## Estructura del Proyecto
- `index.html`: Estructura principal y contenedores de los 4 estados de la interfaz.
- `css/styles.css`: Hojas de estilo modularizadas con paleta de tonos fríos y efectos visuales.
- `js/script.js`: Lógica de procesamiento, simulación de estado de carga ("Pensando...") y derivación a humano.
