# 🍔 Pagina Hamburguesas

## 📌 Descripción
Es una página web que muestra diferentes opciones de comida mediante tarjetas visuales. Los usuarios pueden explorar hamburguesas, consultar sus precios y elegir lo que desean comprar.

## 🚀 Características

- Visualización de productos mediante tarjetas.
- Imágenes de los diferentes alimentos.
- Nombre y descripción de cada producto.
- Precios de los productos.
- Diseño atractivo y organizado.
- Interfaz sencilla y fácil de utilizar.

## 🛠️ Tecnologías utilizadas

- **HTML5:** Estructura de la página web.
- **CSS3:** Estilos, diseño y distribución de las tarjetas.
- **JavaScript:** Funcionalidad e interactividad de la página.

## 🎯 Objetivo

Crear una página web sencilla y atractiva para mostrar productos de comida, permitiendo a los usuarios conocer las diferentes opciones disponibles y facilitar la selección de sus productos favoritos.
