# Vista Previa de Texto

Ejercicio de práctica de **DOM y eventos en JavaScript** (sin backend), enfocado en la sincronización en tiempo real entre una entrada de texto y una vista previa visible, acompañada de conteo de caracteres y alertas de límite.
