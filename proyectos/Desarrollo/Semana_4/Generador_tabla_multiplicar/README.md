# Generador de Tabla de Multiplicar

Ejercicio de práctica de **DOM y eventos en JavaScript** (sin backend), enfocado en la validación numérica previa, el reemplazo dinámico de resultados al generar una nueva tabla y la construcción de una tabla HTML (`<table>`) como reto extra.
