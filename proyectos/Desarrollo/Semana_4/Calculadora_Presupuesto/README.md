# Calculadora de Presupuesto

Ejercicio de práctica de **DOM y eventos en JavaScript** (sin backend), enfocado en la gestión de estado de ingresos y egresos, cálculo dinámico de acumulados y alertas visuales cuando el saldo disponible se vuelve negativo.
